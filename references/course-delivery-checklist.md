# Zlearning 课程文件交付清单

适用于生成 Word、PDF、PPT/PPTX 等课程成品。

## 1. 格式确认

- [ ] 默认主版本为两个独立的可编辑 Word（DOCX）：中文版和英文版。
- [ ] 除非用户明确要求，没有把中英文逐段混排在同一个文件中。
- [ ] 在正式生成前询问用户是否还需要 PDF 和 PPT/PPTX。
- [ ] 用户已明确格式时不重复询问。
- [ ] 用户确认PDF或PPT/PPTX后，默认也分别生成中文和英文版本，除非用户明确只需一种语言。
- [ ] 仅做方案、审计或大纲时不提前触发文件格式确认。

## 2. 版本管理

- [ ] 文件名包含清晰的课程名称、语言标识和版本号。
- [ ] 新版本不覆盖用户要求保留的旧版本。
- [ ] 中文版与英文版的结构、技术结论、案例逻辑和版本号一致。
- [ ] 每种语言的Word、PDF和PPT使用同一版定稿内容。
- [ ] PDF从对应语言的定稿Word或PPT导出。
- [ ] 临时文件和测试导出已清理。
- [ ] 已保存内容源清单及产品、文档版本、日期、语言和适用范围。
- [ ] 已记录源内容版本指纹，能够识别新增或变化内容。
- [ ] 翻译缓存、官方术语表和人工固定边界段落与当前源版本匹配。
- [ ] 已识别所有候选材料中的最新已验收基线，较旧附件没有造成版本或内容回退。
- [ ] 新版本使用独立文件名；在新版本完全验收前，上一版合格文件保持不变。

## 2A. 构建前质量门禁

- [ ] 主内容源已通过模块、时长、学习目标、练习和答案完整性检查。
- [ ] Markdown 表格列数一致，代码围栏成对，无 TODO、TBD 或占位符。
- [ ] 产品名、组件名、缩写、官方术语和关键产品边界检查通过。
- [ ] 版本、兼容性、性能、零停机和零数据丢失等动态或绝对结论已条件化。
- [ ] 质量门禁失败时没有覆盖上一版合格文件。
- [ ] Word、PDF 和 PPT 均从通过门禁的同一语言主内容源构建。

## 3. Word 验收

- [ ] DOCX能被Microsoft Word正常打开。
- [ ] 标题层级、目录和章节顺序正确。
- [ ] 中英文字体、字号、粗细和行距统一。
- [ ] 表格没有明显截断、溢出或过度拥挤。
- [ ] 章节故事位于正式术语说明之前。
- [ ] 分页没有造成标题孤立或大面积异常空白。

## 4. PDF 验收

- [ ] PDF成功导出并可正常打开。
- [ ] 页数和内容与Word定稿版一致。
- [ ] 字体没有替换成异常字形。
- [ ] 表格、分页、页眉页脚和链接显示正常。

## 5. PPT 验收

- [ ] PPTX能被Microsoft PowerPoint正常打开。
- [ ] 幻灯片内容与Word课程主线一致，但不是逐页照搬教材。
- [ ] 每页只保留讲授所需的核心信息。
- [ ] PPT与对应语言定稿Word使用同一版本、术语、案例参数、练习范围和记忆锚点。
- [ ] 已建立Word章节到PPT讲授单元的覆盖映射，主干机制和模块关系没有因压缩而消失。
- [ ] 讲授结构包含课程地图、价值问题、机制或关系、贯穿案例、互动判断、证据解释和总结收口。
- [ ] 长段落已重构为流程、对比、分层、关系或证据卡片，而不是直接缩小字号塞入页面。
- [ ] 术语、模型、对比表和总结没有重新引入旧结论。
- [ ] 演示时长、页数和互动环节符合用户要求。
- [ ] 无旧版本号、旧标题、占位符、错误语言残留或不再采用的固定章节模块。
- [ ] 配套PDF如需交付，由定稿PPT导出。

## 5A. Office与视觉验收策略

- [ ] Word和PPT分别执行限时的打开、统计、导出和视觉检查，没有组合成无界长时间COM任务。
- [ ] 超时或失败时只终止对应的精确进程/会话，并保留上一版合格文件。
- [ ] DOCX/PPTX包结构与XML有效，不存在重复包条目。
- [ ] 已检查旧版本号、旧时长、旧标题、TODO、TBD、占位符和非预期语言残留。
- [ ] Word连续解释没有被过多单单元格表格或卡片切碎。
- [ ] PPT没有机械重复同一版式，且每页只承担一个主要教学动作。
- [ ] 表格和卡片没有明显拥挤；正文不过密；标题不孤立；页面无异常大面积留白。

## 6. 最终交付

- [ ] 文件路径、名称、格式和页数已记录。
- [ ] 明确指出本次生成了哪些版本。
- [ ] 未生成用户没有确认需要的额外格式。
- [ ] 中文版与英文版均已单独记录文件路径、格式和页数/页数范围。
